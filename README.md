# Wandú Landing Page

Estructura base lista para publicar como sitio estático.

## Estructura

`index.html`
Archivo principal del sitio.

`assets/css/styles.css`
Estilos globales de la landing.

`assets/js/main.js`
Interacciones ligeras y animaciones de entrada.

`assets/img/brand/`
Logos y variaciones de marca.

`assets/img/decor/`
Recursos gráficos decorativos.

`reference/`
Material de referencia visual y documentos de trabajo. Esta carpeta no es necesaria para producción.

## Publicación

1. Publica `index.html` junto con la carpeta `assets/`.
2. La carpeta `reference/` es opcional y puede excluirse del despliegue.
3. Antes de publicar, reemplaza los datos de contacto y enlaces finales.

## Pendientes recomendados

- Configurar enlace real de WhatsApp.
- Agregar correo y redes definitivas.
- Reemplazar testimonios temporales por casos reales.
- Optimizar imágenes adicionales si se agregan fotos nuevas.
